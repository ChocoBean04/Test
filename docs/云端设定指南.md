# 云端 Session 设定指南

用 GitHub 仓库开 Claude Code 云端 session 时，能设定的东西分成三个地方：**仓库里的文件**、**GitHub 网页设定**、**Claude 的云端环境设定**。

## 一、已经帮你设好的（仓库里的文件）

| 文件 | 作用 |
|---|---|
| `.claude/skills/` | 15 个 superpowers 技能（brainstorming 等）。用这个仓库开 session 就会自动加载。 |
| `CLAUDE.md` | 给 Claude 的"项目说明"，每次开 session 自动读取：用简体中文、用白话讲技术步骤、文件放哪里、公开仓库不能放什么。 |
| `.claude/settings.json` + `.claude/hooks/session-start.sh` | 开场脚本：每次云端 session 开始时，自动装好做 Word / PPT / PDF / Excel 要用的套件（第一次要多等一会儿，之后只要几秒）。 |
| `.gitignore` | 告诉 Git 哪些暂存文件不要上传（例如 brainstorming 的草图文件）。 |

**你的账号技能**（holiday-activity-book、question-reveal、y1-answer-check、youyouspellingbeehomework、docx、pptx 等）是跟着 claude.ai 账号自动同步的，每个云端 session 都有，不需要放进仓库。想开关哪个技能，到 claude.ai 的设置里改。

> 想改 `CLAUDE.md` 的规则？直接跟 Claude 说"帮我在 CLAUDE.md 加一条……"就行。

## 二、建议你在 GitHub 网页上改的

### 1. 把仓库改成私人（推荐）

现在仓库是**公开**的，任何人都看得到里面的内容。如果以后会放教学资料、秘籍、或自己写的技能，建议改成私人：

仓库页面 → **Settings** → **General** → 拉到最下面 **Danger Zone** → **Change repository visibility** → 选 **Private**。

改成私人后，云端 session 照样能用（Claude 的 GitHub App 已经有这个仓库的权限）。

### 2. 把默认分支改名为 `main`

现在默认分支叫 `claude/zen-wright-k9z017`（第一个 session 自动取的名字）。云端 session 开场时会拿**默认分支**的内容，所以功能上没问题，只是名字难记。想改的话：

仓库页面 → **Settings** → **General** → **Default branch** → 按铅笔图示改名为 `main`。

## 三、Claude 云端环境（Environment）能设的

"环境"就是 session 跑在上面的那台云端电脑的设定。改法：在 session 标题栏点**云端环境菜单** → **Edit**。改完后，**新开的 session** 才会用到。

| 设定 | 用途 | 什么时候要改 |
|---|---|---|
| **Network access**（网络权限） | 决定 Claude 能连哪些网站 | Claude 说"某某网站被挡住了"时，把那个网址加进允许清单 |
| **Setup script**（开机脚本） | 每次开 session 前先跑的安装指令 | 需要的工具跟这个仓库无关、想让所有仓库都有时 |
| **Environment variables / API credentials**（环境变量、API 凭证） | 放 API 密钥等机密 | 要让 Claude 用某个服务、但没有现成的 Connector 时 |

⚠️ 密钥、密码**只放在环境设定里**，不要贴进聊天，也不要写进仓库。

你现在有三个环境：「Use For Testing MCP, Plugin, CLI and Plugin Test」（Jack session 用的就是这个）、「每日资讯进步1%」、「自动更新每日摘要和硅谷来信」。如果想要一个专属的 "Jack" 环境，可以在同一个环境菜单里新增。

官方说明：<https://code.claude.com/docs/en/claude-code-on-the-web>

## 四、其他可以用的功能

- **Connectors（连接器）**：让 Claude 直接读写其他服务。你已经连了 Google Drive、Hugging Face、GitHub。要加新的，到 claude.ai 设置里的 Connectors。
- **Routines（定时任务）**：让 Claude 定时自动做事，例如每天早上整理资讯、每周提醒备课。直接跟 Claude 说"每个星期一早上八点帮我……"就能设。
- **新增自己的技能**：把常做的工作流程（例如做月份练习题）写成技能，放在 `.claude/skills/<技能名>/SKILL.md`，或用 `skill-creator` 技能让 Claude 帮你写。
